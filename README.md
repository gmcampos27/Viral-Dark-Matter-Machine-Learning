# Viral-Dark-Matter-Machine-Learning
Viral Dark Matter classification model

This project uses Machine Learning to classify 34 viral families based on genomic features. It implements two main approaches: **Random Forest** and **XGBoost**.

## 🚀 Features
* Data preprocessing and metadata removal.
* Label encoding for categorical virus families.
* Comparative modeling using RF and XGBoost.
* Model serialization using `joblib`.
